MOBILE COMPUTING ASSIGNMENT - CODES AND OUTPUTS

Files:
- cellular_network_planner.py: integrated Python 3 program.
- outputs/sample_output.txt: console output from running the program.
- outputs/cell_count_comparison.png: cell count graph.
- outputs/sir_vs_cluster_size.png: SIR graph.
- outputs/traffic_growth.png: subscriber traffic graph.

Run:
python cellular_network_planner.py

The Python program uses only the Python standard library. No NumPy or other package is required.
